\doxysubsection{Detailed Description}
Documented background module


\begin{DoxyItemize}
\item Julien Lesgourgues, 17.\+04.\+2011
\item routines related to ncdm written by T. Tram in 2011
\end{DoxyItemize}

Deals with the cosmological background evolution. This module has two purposes\+:


\begin{DoxyItemize}
\item at the beginning, to initialize the background, i.\+e. to integrate the background equations, and store all background quantities as a function of conformal time inside an interpolation table.
\item to provide routines which allow other modules to evaluate any background quantity for a given value of the conformal time (by interpolating within the interpolation table), or to find the correspondence between redshift and conformal time.
\end{DoxyItemize}

The overall logic in this module is the following\+:


\begin{DoxyEnumerate}
\item most background parameters that we will call \{A\} (e.\+g. rho\+\_\+gamma, ..) can be expressed as simple analytical functions of a few variables that we will call \{B\} (in simplest models, of the scale factor \textquotesingle{}a\textquotesingle{}; in extended cosmologies, of \textquotesingle{}a\textquotesingle{} plus e.\+g. (phi, phidot) for quintessence, or some temperature for exotic particles, etc...).
\item in turn, quantities \{B\} can be found as a function of conformal time by integrating the background equations.
\item some other quantities that we will call \{C\} (like e.\+g. the sound horizon or proper time) also require an integration with respect to time, that cannot be inferred analytically from parameters \{B\}.
\end{DoxyEnumerate}

So, we define the following routines\+:


\begin{DoxyItemize}
\item \mbox{\hyperlink{background_8c_a302eb502773905601fa9b6936840682a}{background\+\_\+functions()}} returns all background quantities \{A\} as a function of quantities \{B\}.
\item \mbox{\hyperlink{background_8c_aeb523f9c8e728f79e9b431d2020faa41}{background\+\_\+solve()}} integrates the quantities \{B\} and \{C\} with respect to conformal time; this integration requires many calls to \mbox{\hyperlink{background_8c_a302eb502773905601fa9b6936840682a}{background\+\_\+functions()}}.
\item the result is stored in the form of a big table in the background structure. There is one column for conformal time \textquotesingle{}tau\textquotesingle{}; one or more for quantities \{B\}; then several columns for quantities \{A\} and \{C\}.
\end{DoxyItemize}

Later in the code, if we know the variables \{B\} and need some quantity \{A\}, the quickest and most precise way is to call directly \mbox{\hyperlink{background_8c_a302eb502773905601fa9b6936840682a}{background\+\_\+functions()}} (for instance, in simple models, if we want H at a given value of the scale factor). If we know \textquotesingle{}tau\textquotesingle{} and want any other quantity, we can call \mbox{\hyperlink{background_8c_ac47004414b208d36153f35d8465cace2}{background\+\_\+at\+\_\+tau()}}, which interpolates in the table and returns all values. Finally it can be useful to get \textquotesingle{}tau\textquotesingle{} for a given redshift \textquotesingle{}z\textquotesingle{}\+: this can be done with \mbox{\hyperlink{background_8c_a868e85eefe464a31b25639170ff9550c}{background\+\_\+tau\+\_\+of\+\_\+z()}}. So if we are somewhere in the code, knowing z and willing to get background quantities, we should call first \mbox{\hyperlink{background_8c_a868e85eefe464a31b25639170ff9550c}{background\+\_\+tau\+\_\+of\+\_\+z()}} and then \mbox{\hyperlink{background_8c_ac47004414b208d36153f35d8465cace2}{background\+\_\+at\+\_\+tau()}}.

In order to save time, \mbox{\hyperlink{background_8c_ac47004414b208d36153f35d8465cace2}{background\+\_\+at\+\_\+tau()}} can be called in three modes\+: short\+\_\+info, normal\+\_\+info, long\+\_\+info (returning only essential quantities, or useful quantities, or rarely useful quantities). Each line in the interpolation table is a vector whose first few elements correspond to the short\+\_\+info format; a larger fraction contribute to the normal format; and the full vector corresponds to the long format. The guideline is that short\+\_\+info returns only geometric quantities like a, H, H\textquotesingle{}; normal format returns quantities strictly needed at each step in the integration of perturbations; long\+\_\+info returns quantities needed only occasionally.

In summary, the following functions can be called from other modules\+:


\begin{DoxyEnumerate}
\item \mbox{\hyperlink{background_8c_afeb0656453b92be39c60fb3fb1abd910}{background\+\_\+init()}} at the beginning
\item \mbox{\hyperlink{background_8c_ac47004414b208d36153f35d8465cace2}{background\+\_\+at\+\_\+tau()}}, \mbox{\hyperlink{background_8c_a868e85eefe464a31b25639170ff9550c}{background\+\_\+tau\+\_\+of\+\_\+z()}} at any later time
\item \mbox{\hyperlink{background_8c_a5b0d8db279856b3c96aba08c83aa19d6}{background\+\_\+free()}} at the end, when no more calls to the previous functions are needed 
\end{DoxyEnumerate}
