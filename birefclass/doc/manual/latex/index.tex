(the information below can also be found on the webpage, just below the download button)

Download the code from the webpage and unpack the archive (tar -\/zxvf class\+\_\+vx.\+y.\+z.\+tar.\+gz), or clone it from \href{https://github.com/lesgourg/class_public}{\texttt{ https\+://github.\+com/lesgourg/class\+\_\+public}}. Go to the class directory (cd class/ or class\+\_\+public/ or class\+\_\+vx.\+y.\+z/) and compile (make clean; make class). You can usually speed up compilation with the option -\/j\+: make -\/j class. If the first compilation attempt fails, you may need to open the Makefile and adapt the name of the compiler (default\+: gcc), of the optimization flag (default\+: -\/O4 -\/ffast-\/math) and of the Open\+MP flag (default\+: -\/fopenmp; this flag is facultative, you are free to compile without Open\+MP if you don\textquotesingle{}t want parallel execution; note that you need the version 4.\+2 or higher of gcc to be able to compile with -\/fopenmp). Many more details on the CLASS compilation are given on the wiki page

\href{https://github.com/lesgourg/class_public/wiki/Installation}{\texttt{ https\+://github.\+com/lesgourg/class\+\_\+public/wiki/\+Installation}}

(in particular, for compiling on Mac $>$= 10.\+9 despite of the clang incompatibility with Open\+MP).

To check that the code runs, type\+: \begin{DoxyVerb}./class explanatory.ini
\end{DoxyVerb}
 The explanatory.\+ini file is THE reference input file, containing and explaining the use of all possible input parameters. We recommend to read it, to keep it unchanged (for future reference), and to create for your own purposes some shorter input files, containing only the input lines which are useful for you. Input files must have a $\ast$.ini extension.

If you want to play with the precision/speed of the code, you can use one of the provided precision files (e.\+g. cl\+\_\+permille.\+pre) or modify one of them, and run with two input files, for instance\+: \begin{DoxyVerb}./class test.ini cl_permille.pre
\end{DoxyVerb}
 The files $\ast$.pre are suppposed to specify the precision parameters for which you don\textquotesingle{}t want to keep default values. If you find it more convenient, you can pass these precision parameter values in your $\ast$.ini file instead of an additional $\ast$.pre file.

 On top of that, if you wish to modify the code, you will find lots of comments directly in the files.\hypertarget{index_autotoc_md1}{}\doxysection{Python}\label{index_autotoc_md1}

This can be done by typing just \textquotesingle{}make\textquotesingle{} instead of \textquotesingle{}make class\textquotesingle{} (or for speeding up\+: \textquotesingle{}make -\/j\textquotesingle{}). More details on the wrapper and its compilation are found on the wiki page

\href{https://github.com/lesgourg/class_public/wiki}{\texttt{ https\+://github.\+com/lesgourg/class\+\_\+public/wiki}}\hypertarget{index_autotoc_md2}{}\doxysection{Plotting utility}\label{index_autotoc_md2}
Since version 2.\+3, the package includes an improved plotting script called CPU.\+py (Class Plotting Utility), written by Benjamin Audren and Jesus Torrado. It can plot the Cl\textquotesingle{}s, the P(k) or any other CLASS output, for one or several models, as well as their ratio or percentage difference. The syntax and list of available options is obtained by typing \textquotesingle{}pyhton CPU.\+py -\/h\textquotesingle{}. There is a similar script for MATLAB, written by Thomas Tram. To use it, once in MATLAB, type \textquotesingle{}help plot\+\_\+\+CLASS\+\_\+output.\+m\textquotesingle{}\hypertarget{index_autotoc_md3}{}\doxysection{Developing the code}\label{index_autotoc_md3}
