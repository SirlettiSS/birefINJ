\doxysubsection{Detailed Description}
Documented lensing module

Simon Prunet and Julien Lesgourgues, 6.\+12.\+2010

This module computes the lensed temperature and polarization anisotropy power spectra $ C_l^{X}, P(k), ... $\textquotesingle{}s given the unlensed temperature, polarization and lensing potential spectra.

Follows Challinor and Lewis full-\/sky method, astro-\/ph/0502425

The following functions can be called from other modules\+:


\begin{DoxyEnumerate}
\item \mbox{\hyperlink{lensing_8c_a3b33ec98a680b47da64235ebf899439a}{lensing\+\_\+init()}} at the beginning (but after \mbox{\hyperlink{spectra_8c_a192c3cc36d17f276ed7b5d7e485e70f1}{spectra\+\_\+init()}})
\item \mbox{\hyperlink{lensing_8c_ac5710eca0f1143cd1ad7a204cbe4bae5}{lensing\+\_\+cl\+\_\+at\+\_\+l()}} at any time for computing Cl\+\_\+lensed at any l
\item \mbox{\hyperlink{lensing_8c_a9cbf409f2b65914598cf452b51685dca}{lensing\+\_\+free()}} at the end 
\end{DoxyEnumerate}

Anisotropy power spectra $ C_l$\textquotesingle{}s for all types, modes and initial conditions. SO FAR\+: ONLY SCALAR

This routine evaluates all the lensed $ C_l$\textquotesingle{}s at a given value of l by picking it in the pre-\/computed table. When relevant, it also sums over all initial conditions for each mode, and over all modes.

This function can be called from whatever module at whatever time, provided that \mbox{\hyperlink{lensing_8c_a3b33ec98a680b47da64235ebf899439a}{lensing\+\_\+init()}} has been called before, and \mbox{\hyperlink{lensing_8c_a9cbf409f2b65914598cf452b51685dca}{lensing\+\_\+free()}} has not been called yet.

\item check that we really want to compute at least one spectrum
\item initialize indices and allocate some of the arrays in the lensing structure
\item put all precision variables hare; will be stored later in precision structure
\item Last element in $ \mu $ will be for $ \mu=1 $, needed for sigma2. The rest will be chosen as roots of a Gauss-\/\+Legendre quadrature
\item allocate array of $ \mu $ values, as well as quadrature weights
\item Compute $ d^l_{mm\textnormal{\textquotesingle}} (\mu) $
\item Allocate main contiguous buffer
\item compute $ Cgl(\mu)$, $ Cgl2(\mu) $ and sigma2( $\mu$)
\item Locally store unlensed temperature $ cl_{tt}$ and potential $ cl_{pp}$ spectra
\item Compute sigma2 $(\mu)$ and Cgl2( $\mu$)
\item compute ksi, ksi+, ksi-\/, ksiX
\item -\/-\/$>$ ksi is for TT
\item -\/-\/$>$ ksiX is for TE
\item -\/-\/$>$ ksip, ksim for EE, BB
\item compute lensed $ C_l$\textquotesingle{}s by integration
\item spline computed $ C_l$\textquotesingle{}s in view of interpolation
\item Free lots of stuff
