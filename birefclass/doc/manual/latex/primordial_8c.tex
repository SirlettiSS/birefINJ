\doxysubsection{Detailed Description}
Documented primordial module.

Julien Lesgourgues, 24.\+08.\+2010

This module computes the primordial spectra. It can be used in different modes\+: simple parametric form, evolving inflaton perturbations, etc. So far only the mode corresponding to a simple analytic form in terms of amplitudes, tilts and runnings has been developed.

The following functions can be called from other modules\+:


\begin{DoxyEnumerate}
\item \mbox{\hyperlink{primordial_8c_aa8514e84606dae204881c26add8347fd}{primordial\+\_\+init()}} at the beginning (anytime after \mbox{\hyperlink{perturbations_8c_a8c49cf2b10de95fbf09d8823bc37c512}{perturb\+\_\+init()}} and before \mbox{\hyperlink{spectra_8c_a192c3cc36d17f276ed7b5d7e485e70f1}{spectra\+\_\+init()}})
\item \mbox{\hyperlink{primordial_8c_a89f883182d64a767893f44af3cc76156}{primordial\+\_\+spectrum\+\_\+at\+\_\+k()}} at any time for computing P(k) at any k
\item \mbox{\hyperlink{primordial_8c_a0738267288f804baecaabf57d018dd4c}{primordial\+\_\+free()}} at the end 
\end{DoxyEnumerate}

Primordial spectra for arbitrary argument and for all initial conditions.

This routine evaluates the primordial spectrum at a given value of k by interpolating in the pre-\/computed table.

When k is not in the pre-\/computed range but the spectrum can be found analytically, it finds it. Otherwise returns an error.

Can be called in two modes; linear or logarithmic\+:


\begin{DoxyItemize}
\item linear\+: takes k, returns P(k)
\item logarithmic\+: takes ln(k), return ln(\+P(k))
\end{DoxyItemize}

One little subtlety\+: in case of several correlated initial conditions, the cross-\/correlation spectrum can be negative. Then, in logarithmic mode, the non-\/diagonal elements contain the cross-\/correlation angle $ P_{12}/\sqrt{P_{11} P_{22}}$ (from -\/1 to 1) instead of $\ln{P_{12}}$

This function can be called from whatever module at whatever time, provided that \mbox{\hyperlink{primordial_8c_aa8514e84606dae204881c26add8347fd}{primordial\+\_\+init()}} has been called before, and \mbox{\hyperlink{primordial_8c_a0738267288f804baecaabf57d018dd4c}{primordial\+\_\+free()}} has not been called yet.
