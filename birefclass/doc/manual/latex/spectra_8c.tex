\doxysubsection{Detailed Description}
Documented spectra module

Julien Lesgourgues, 1.\+11.\+2019

This module computes the harmonic power spectra $ C_l^{X} $\textquotesingle{}s given the transfer functions and the primordial spectra.

The following functions can be called from other modules\+:


\begin{DoxyEnumerate}
\item \mbox{\hyperlink{spectra_8c_a192c3cc36d17f276ed7b5d7e485e70f1}{spectra\+\_\+init()}} at the beginning (but after \mbox{\hyperlink{transfer_8c_a7ed9b28044b1e58d74494915b3ff5b10}{transfer\+\_\+init()}})
\item \mbox{\hyperlink{spectra_8c_a474a08a4d11642f6e688524556442909}{spectra\+\_\+cl\+\_\+at\+\_\+l()}} at any time for computing individual $ C_l $\textquotesingle{}s at any l
\item \mbox{\hyperlink{spectra_8c_acbfeac6ad88fa757677b47d76722aec3}{spectra\+\_\+free()}} at the end 
\end{DoxyEnumerate}

Anisotropy power spectra $ C_l$\textquotesingle{}s for all types, modes and initial conditions.

This routine evaluates all the $C_l$\textquotesingle{}s at a given value of l by interpolating in the pre-\/computed table. When relevant, it also sums over all initial conditions for each mode, and over all modes.

This function can be called from whatever module at whatever time, provided that \mbox{\hyperlink{spectra_8c_a192c3cc36d17f276ed7b5d7e485e70f1}{spectra\+\_\+init()}} has been called before, and \mbox{\hyperlink{spectra_8c_acbfeac6ad88fa757677b47d76722aec3}{spectra\+\_\+free()}} has not been called yet.
